# Word Processor

A set of text-processing functions: split text on several delimiters, list words longer than a length, map word lengths, count letters, and find the most used character.

## What it practises

- Lists and dictionaries
- List and dictionary comprehensions
- `map` and `filter`

## Run it

From this folder:

```bash
python3 -c "import word_processor as w; print(w.words_lengths_map('the cat sat on the mat'))"
```

## Test it

```bash
python3 -m unittest
```
