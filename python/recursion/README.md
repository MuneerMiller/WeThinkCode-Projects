# Recursion

Three functions written with recursion instead of loops: the smallest number in a list, the sum of a list, and every possible string of a given length from a set of characters.

## What it practises

- Base cases and recursive cases
- Thinking about a problem as a smaller version of itself

## Run it

From this folder:

```bash
python3 -c "import super_algos as s; print(s.find_possible_strings(['a', 'b'], 2))"
```

## Test it

```bash
python3 -m unittest
```
