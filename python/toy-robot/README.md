# Toy Robot 1: Movement Patterns

The first Toy Robot step. The robot prints the moves it would make to trace a square, a rectangle, a circle, a "dancing square" and "crop circles".

## What it practises

- Functions with parameters
- Functions calling other functions
- `for` loops

## Run it

From this folder:

```bash
python3 robot.py
```

## Test it

```bash
python3 -m unittest
```
