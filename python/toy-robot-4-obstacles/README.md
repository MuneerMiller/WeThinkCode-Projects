# Toy Robot 4: Obstacles

The robot from Toy Robot 3 in a world with random obstacles that block its path. The world is split into its own modules, so it can run as text in the terminal or be drawn with turtle graphics.

## What it practises

- Splitting a program into modules and packages
- Choosing a module at runtime from command-line arguments
- Collision checks along a path

## Run it

From this folder:

```bash
python3 robot.py          # text world
python3 robot.py turtle   # turtle graphics (needs tkinter)
```

## Test it

```bash
python3 -m unittest
```
