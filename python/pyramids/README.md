# Pyramids

Draws shapes in the terminal: pyramid, square, triangle, diamond, rhombus or inverted triangle, at any height and either solid or outlined.

## What it practises

- Nested loops
- Building strings of spaces and stars
- Validating input before using it

## Run it

From this folder:

```bash
python3 draw.py
```

Example: a diamond of height 4:

```
     *
    ***
   *****
  *******
   *****
    ***
     *
```

## Test it

```bash
python3 -m unittest
```
