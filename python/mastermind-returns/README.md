# Mastermind: Return Values

Mastermind again, with functions that return values instead of printing. Each part can then be tested on its own: I wrote `test_functions.py` alongside WeThinkCode_'s tests, using `unittest.mock` to fake keyboard input.

## What it practises

- Return values versus side effects
- Writing my own unit tests
- Mocking `input()` in tests

## Run it

From this folder:

```bash
python3 mastermind.py
```

## Test it

```bash
python3 -m unittest
```
