# WTC Basics

My first WeThinkCode_ exercise: a function that prints `Hello World!`, checked by a unit test.

## What it practises

- Writing and calling a function
- Running a program and its tests from the terminal

## Run it

From this folder:

```bash
python3 hello.py
```

## Test it

```bash
python3 -m unittest
```
