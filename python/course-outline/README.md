# Course Outline

Builds and prints an outline of a course: its topics in order, three problems per topic, and each student's progress.

## What it practises

- Classes and objects (`Problem` with `__str__`)
- Sets, tuples and dictionaries
- Sorting with a custom key

## Run it

From this folder:

```bash
python3 course.py
```

## Test it

```bash
python3 -m unittest
```
